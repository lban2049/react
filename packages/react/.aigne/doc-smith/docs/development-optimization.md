# Development and Optimization

This section provides guidance on enhancing the performance and simplifying the debugging process for your React applications, especially within development environments. It covers specific tools and crucial build considerations that contribute to a smoother development workflow and a more optimized end product. You will find more detailed information in its sub-sections: [Debugging Utilities](./development-optimization-debugging.md) and [Compiler Runtime](./development-optimization-compiler-runtime.md).

## Debugging Utilities

Effective debugging is essential during application development. This part introduces development-only tools designed to help you inspect component behavior, understand rendering flows, and pinpoint issues that might affect your application's performance or correctness. Key utilities like `useDebugValue` and `captureOwnerStack` are specifically available in development mode to assist with these tasks.

For an in-depth look at these debugging utilities and how to leverage them, refer to the [Debugging Utilities](./development-optimization-debugging.md) section.

## Compiler Runtime

React's performance can be significantly improved through compile-time optimizations. This segment focuses on the React Compiler Runtime, explaining its function and how it contributes to optimizing your application. It covers specific exports, such as `useMemoCache` (also aliased as `c`), which are integral to these compile-time enhancements.

To understand the full capabilities and usage of the React Compiler Runtime, please visit the [Compiler Runtime](./development-optimization-compiler-runtime.md) section.

Understanding these development and optimization aspects will equip you with the knowledge and tools necessary to build robust, high-performance React applications. For more detailed information on each topic, please navigate to the dedicated sub-sections: [Debugging Utilities](./development-optimization-debugging.md) and [Compiler Runtime](./development-optimization-compiler-runtime.md).
