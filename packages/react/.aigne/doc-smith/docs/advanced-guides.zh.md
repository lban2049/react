# 高级指南

本节深入探讨了面向经验丰富的 React 开发人员的高级主题、专门环境和前沿功能。如果你希望优化应用程序、利用服务器端功能或体验 React 的未来，那么这里就是你的最佳选择。

下面的每个指南都提供了有关 React 更复杂功能的特定领域的深入信息。

  </x-card>
  <x-card data-title="JSX 运行时" data-icon="lucide:code" data-href="/advanced-guides/jsx-runtime">

  </x-card>
  <x-card data-title="编译器运行时" data-icon="lucide:bot" data-href="/advanced-guides/compiler-runtime">

  </x-card>
  <x-card data-title="实验性 API" data-icon="lucide:flask-conical" data-href="/advanced-guides/experimental">

</x-cards>

这些指南旨在深入介绍 React 中更复杂的方面。在探索了这些主题之后，你可能还会发现全面的 [API 参考](./api-reference.md) 对于了解特定函数和钩子的详细信息很有用。
