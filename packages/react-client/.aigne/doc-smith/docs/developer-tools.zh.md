# 开发工具与调试

对于使用 `react-client` 的架构师和开发人员而言，了解应用程序的内部行为对于高效的分析、调试和优化至关重要。本节概述了旨在帮助您深入了解 `react-client` 操作的工具和集成，特别是关于服务器组件渲染和数据流的方面。

深入了解以下小节，获取有关如何利用这些功能的详细指导：

## 开发工具集成
了解 `react-client` 如何与 React DevTools 集成。这种集成支持对服务器组件渲染进行深度检查和性能分析，从而提供对 UI 服务器驱动方面的可见性。

[开发工具集成](./developer-tools-devtools-integration.md)

## 性能追踪
了解可用于服务器组件和 I/O 操作的性能测量和日志记录功能。本节详细介绍了如何解释性能分析数据以识别瓶颈并优化应用程序的性能。

[性能追踪](./developer-tools-performance-tracking.md)

## 控制台回放
了解直接在客户端开发环境中回放服务器端控制台日志及其关联堆栈跟踪的机制。此功能通过将服务器日志引入本地控制台，简化了调试过程。

[控制台回放](./developer-tools-console-replay.md)

## 错误与推迟处理
探索管理和报告源自服务器的错误和内容推迟的策略。这包括了解为协助诊断和解决问题而提供的具体调试信息。

[错误与推迟处理](./developer-tools-error-postponement-handling.md)
