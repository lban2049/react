# 内部类型和事件

本节概述了 `react-art` 用于表示图形元素的内部 ART 原生类型，并详细说明了在 `react-art` 环境中如何处理用户交互事件。理解这些内部机制对于高级定制和调试至关重要。有关 `react-art` 如何与 React 协调过程集成的更多信息，请参阅[与 React 集成](./core-concepts-integration-with-react.md)。

### 创建实例和应用属性

```mermaid
sequenceDiagram
  participant ReactComponent as "React 组件"
  participant ReactART as "React ART"
  participant InternalARTType as "ART 实例（例如，Shape, Group）"
  
  ReactComponent->>ReactART: 渲染组件（例如，<Shape />）
  ReactART->>ReactART: 识别 ART 类型（例如，TYPES.SHAPE）
  ReactART->>InternalARTType: 调用 Mode.Shape()（创建原生 ART 对象）
  InternalARTType->>InternalARTType: 分配 _applyProps 方法（例如，applyShapeProps）
  ReactART->>InternalARTType: 初始属性应用（instance._applyProps(instance, props)）
  Note over InternalARTType: 应用默认和初始属性，如变换、填充、描边、路径
  
  alt 后续渲染及属性更新
    ReactComponent->>ReactART: 使用新属性重新渲染
    ReactART->>InternalARTType: 调用 instance._applyProps(instance, newProps, oldProps)
    Note over InternalARTType: 高效地只更新更改的属性
  end

  InternalARTType->>InternalARTType: 渲染/更新内部状态
```

## 事件处理机制

`react-art` 提供了一个健壮的事件处理系统，允许您将监听器附加到 ART 元素上，从而实现交互式图形。这种机制与您在标准 DOM 环境中找到的事件处理方式非常相似。

以下是支持的事件类型：

| 事件类型    | 对应的 React 属性 | 描述                                   |
| :------------ | :----------------------- | :-------------------------------------------- |
| `点击`       | `onClick`                | 当元素被点击时触发。          |
| `鼠标移动`   | `onMouseMove`            | 当鼠标在元素上移动时触发。|
| `鼠标移入`   | `onMouseOver`            | 当鼠标进入元素时触发。    |
| `鼠标移出`   | `onMouseOut`             | 当鼠标离开元素时触发。    |
| `鼠标抬起`     | `onMouseUp`              | 当鼠标按钮在元素上释放时触发。 |
| `鼠标按下`   | `onMouseDown`            | 当鼠标按钮在元素上按下时触发。 |

### 事件处理内部工作原理

事件监听器通过 `addEventListeners`、`createEventHandler` 和 `destroyEventListeners` 等内部方法进行管理。当您为 React ART 组件提供事件属性（例如 `onClick`）时，`addEventListeners` 会将此函数注册到底层的 ART 实例。它将监听器存储在 `instance._listeners` 中，并在 `instance._subscriptions` 中管理一个可用于取消订阅的 `subscription`。

`createEventHandler` 生成一个接收原生 ART 事件的包装函数。此包装函数随后将事件分派到您的原始 React 属性监听器。当 ART 实例从树中移除时，`destroyEventListeners` 会清理所有相关的订阅，从而防止内存泄漏。

```mermaid
sequenceDiagram
  participant YourComponent as "您的 ReactART 组件"
  participant ReactARTInstance as "ART 实例（例如，Shape）"
  participant NativeART as "底层 ART 库"

  YourComponent->>ReactARTInstance: 使用事件属性渲染（例如，onClick={handleClick}）
  ReactARTInstance->>ReactARTInstance: 调用 addEventListeners("click", handleClick)
  ReactARTInstance->>ReactARTInstance: 将 handleClick 存储在 instance._listeners 中
  ReactARTInstance->>ReactARTInstance: 创建包装函数（createEventHandler）
  ReactARTInstance->>NativeART: 使用包装函数订阅原生“click”事件
  NativeART-->>ReactARTInstance: 用户交互（例如，实际点击）
  NativeART->>ReactARTInstance: 触发原生“click”事件
  ReactARTInstance->>ReactARTInstance: 调用包装函数 handleEvent(event)
  ReactARTInstance->>YourComponent: 调用 instance._listeners["click"].call(instance, event)
  YourComponent->>ReactARTInstance: 组件卸载
  ReactARTInstance->>ReactARTInstance: 调用 destroyEventListeners()
  ReactARTInstance->>NativeART: 取消订阅所有原生事件
  Note over ReactARTInstance: 清除 instance._listeners 和 instance._subscriptions
```
