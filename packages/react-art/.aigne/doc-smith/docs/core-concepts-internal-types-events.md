# Internal Types and Events

This section outlines the internal ART primitive types that `react-art` uses to represent your graphical elements and details how user interaction events are handled within the `react-art` environment. Understanding these internal mechanisms is crucial for advanced customization and debugging. For more on how `react-art` integrates with React's reconciliation process, see [Integration with React](./core-concepts-integration-with-react.md).

## Internal ART Types

When you define components like `<Shape>`, `<Group>`, `<Text>`, or `<ClippingRectangle>` in React ART, they are mapped to corresponding internal ART primitive types. The `createInstance` function is responsible for creating these instances based on the component `type` and applying their initial properties. Each instance is then associated with a specific internal method, `_applyProps`, which handles updating its visual and interactive properties.

### Creating Instances and Applying Properties

```mermaid
sequenceDiagram
  participant ReactComponent as "React Component"
  participant ReactART as "React ART"
  participant InternalARTType as "ART Instance (e.g., Shape, Group)"
  
  ReactComponent->>ReactART: Render component (e.g., <Shape />)
  ReactART->>ReactART: Identify ART TYPE (e.g., TYPES.SHAPE)
  ReactART->>InternalARTType: Call Mode.Shape() (create native ART object)
  InternalARTType->>InternalARTType: Assign _applyProps method (e.g., applyShapeProps)
  ReactART->>InternalARTType: Initial property application (instance._applyProps(instance, props))
  Note over InternalARTType: Applies default and initial props like transform, fill, stroke, path
  
  alt Subsequent Render with Prop Updates
    ReactComponent->>ReactART: Re-render with new props
    ReactART->>InternalARTType: Call instance._applyProps(instance, newProps, oldProps)
    Note over InternalARTType: Efficiently updates only changed properties
  end

  InternalARTType->>InternalARTType: Render/Update internal state
```

## Event Handling Mechanism

`react-art` provides a robust event handling system that allows you to attach listeners to your ART elements, enabling interactive graphics. This mechanism closely mirrors the event handling you'd find in a standard DOM environment.

The following are the supported event types:

| Event Type    | Corresponding React Prop | Description                                   |
| :------------ | :----------------------- | :-------------------------------------------- |
| `click`       | `onClick`                | Triggers when an element is clicked.          |
| `mousemove`   | `onMouseMove`            | Triggers when the mouse moves over an element.|
| `mouseover`   | `onMouseOver`            | Triggers when the mouse enters an element.    |
| `mouseout`    | `onMouseOut`             | Triggers when the mouse leaves an element.    |
| `mouseup`     | `onMouseUp`              | Triggers when a mouse button is released over an element. |
| `mousedown`   | `onMouseDown`            | Triggers when a mouse button is pressed over an element. |

### How Event Handling Works Internally

Event listeners are managed through internal methods like `addEventListeners`, `createEventHandler`, and `destroyEventListeners`. When you provide an event prop (e.g., `onClick`) to a React ART component, `addEventListeners` registers this function with the underlying ART instance. It stores the listener in `instance._listeners` and manages a `subscription` in `instance._subscriptions` that can be used to unsubscribe.

`createEventHandler` generates a wrapper function that receives the native ART event. This wrapper then dispatches the event to your original React prop listener. When an ART instance is removed from the tree, `destroyEventListeners` cleans up all associated subscriptions, preventing memory leaks.

```mermaid
sequenceDiagram
  participant YourComponent as "Your ReactART Component"
  participant ReactARTInstance as "ART Instance (e.g., Shape)"
  participant NativeART as "Underlying ART Library"

  YourComponent->>ReactARTInstance: Render with event prop (e.g., onClick={handleClick})
  ReactARTInstance->>ReactARTInstance: Call addEventListeners("click", handleClick)
  ReactARTInstance->>ReactARTInstance: Store handleClick in instance._listeners
  ReactARTInstance->>ReactARTInstance: Create wrapper function (createEventHandler)
  ReactARTInstance->>NativeART: Subscribe to native "click" event with wrapper
  NativeART-->>ReactARTInstance: User interaction (e.g., actual click)
  NativeART->>ReactARTInstance: Trigger native "click" event
  ReactARTInstance->>ReactARTInstance: Wrapper function handleEvent(event) invoked
  ReactARTInstance->>YourComponent: Call instance._listeners["click"].call(instance, event)
  YourComponent->>ReactARTInstance: Component unmounts
  ReactARTInstance->>ReactARTInstance: Call destroyEventListeners()
  ReactARTInstance->>NativeART: Unsubscribe all native events
  Note over ReactARTInstance: Clear instance._listeners and instance._subscriptions
```
