# 实验状态和警告

本节概述了 `react-cache` 的实验性质、其固有的不稳定性以及有关其使用的重要警告。有关其目的的概述，请参阅[概述](./Overview.md)部分。

`react-cache` 旨在专门与实验性、尚未发布的 React 功能配合使用。它不适用于一般用途，仅用于特定演示场景，并作为更高级缓存实现的参考。

## 不稳定的 API

`react-cache` 的 API 极不稳定。它将在不同版本之间经历重大且频繁的更改。您不应期望 API 稳定性，任何依赖其当前形态的代码都可能在不另行通知的情况下损坏。

## 请勿在生产环境中使用

务必理解 `react-cache` 发布的目的仅为演示和实验。**请勿在任何实际或生产关键型应用程序中使用此包。** 使用它会带来重大风险，包括不可预测的行为、破坏性更改以及缺乏对生产环境的支持。

**使用风险自负。**

此包旨在演示潜在的缓存实现和未来的 React 功能，而非作为当前应用程序开发的稳定库。对于生产环境中的稳定缓存解决方案，请考虑其他方法。
